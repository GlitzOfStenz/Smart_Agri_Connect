# 🌾 Smart Agri-Connect

Smart Agri-Connect is a smart web-based agricultural platform that connects farmers directly with buyers and retailers to remove middlemen and improve farmer income.

---

## 🚀 Features

- AI-based demand prediction  
- Unsold crop risk prediction  
- District-wise crop heatmap  
- Voice & multilingual support  
- Real-time chat between farmers and buyers  
- Weather and market insights  
- Offline-first functionality  
- Local delivery integration  
- Rating and review system  

---

## 🛠️ Tech Stack

- HTML  
- CSS  
- JavaScript  
- Node.js  

---

## 🎯 Goal

To reduce crop wastage, remove middlemen exploitation, and increase farmer income using smart technology.
